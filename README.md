🛒 বাজার দর | BazarDor

BazarDor is a modern, responsive web application that helps users explore essential commodity prices, track price fluctuations, and compare market prices through an intuitive interface.

🛠️ Technologies Used

* Framework: Next.js 15 (App Router)
* Language: JavaScript (JSX)
* Styling: Tailwind CSS, DaisyUI
* Authentication: Better Auth
* Notifications: react-hot-toast
* Icons: Lucide React

✨ Key Features

1. Market Price Ticker: Displays product prices and price-change indicators.
2. Product Listings: Browse essential commodities with prices and market trends.
3. Authentication: User registration, login, and social authentication.
4. Price Sorting (C1): Sort products by price, supporting Bengali numerals.
5. Profile Management (C3): View and update user profile information.
6. Responsive Design: Optimized for mobile, tablet, and desktop.
7. Loading & Notifications: Skeleton loaders and toast messages.
8. Product Details: Explore product information and market-wise prices.

🚀 Getting Started

git clone YOUR_REPOSITORY_URL
cd YOUR_PROJECT_FOLDER

npm run dev

Open http://localhost:3000 in your browser.

Note: Configure the required environment variables before running authentication features.
